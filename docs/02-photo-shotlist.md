# Photo shot list

Photos are what make the site look expensive. Everything below is a slot the site is ready
for: add the file to `public/images/…`, register it in `src/data/photos.ts` (with its real
width and height), and point the product or page at it. Nothing on the site crops a photo,
so frame each one the way it should display.

**Rules of thumb**
- Daylight, no flash. Blinds half lowered usually read better than fully down.
- Tidy the sill. No cables, remotes or cardboard in frame.
- Shoot from slightly below eye level, square to the window, phone held level.
- Landscape for wide windows and rooms; portrait (4:5) for a single tall window.
- Send the original file from the phone or camera, not a WhatsApp or Google download.
  The 5 photos we have are Google's downsized copies (~1360 px); the home hero wants ≥2400 px.
